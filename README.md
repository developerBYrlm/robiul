### 🗓️ Exam Management Portal — *MERN Stack*

<p>
<img src="https://img.shields.io/badge/React-61DAFB?style=flat-square&logo=react&logoColor=black" />
<img src="https://img.shields.io/badge/Express.js-000000?style=flat-square&logo=express&logoColor=white" />
<img src="https://img.shields.io/badge/MongoDB-47A248?style=flat-square&logo=mongodb&logoColor=white" />
<img src="https://img.shields.io/badge/node--cron-339933?style=flat-square&logo=nodedotjs&logoColor=white" />
</p>

A role-based exam scheduling system built for academic departments.

- 👥 **Multi-role access control** — Authority, Student, Faculty, ACAD, and IT — scoped per department (CSE, EEE, BBA, Law, IT)
- 📆 Department authorities independently set application deadlines and special exam dates
- ✉️ **Automated reminder emails** to students via a scheduled `node-cron` job
- 🐛 Diagnosed and fixed a production bug where schedules leaked globally instead of staying department-isolated
