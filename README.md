### 🚀 Featured Project

**🗓️ Exam Management Portal** — *MERN Stack*

A role-based exam scheduling system for academic departments, built with React, Express/Node, and MongoDB (Mongoose).

- 👥 Multi-role access control — **Authority, Student, Faculty, ACAD, IT** — scoped per department (CSE, EEE, BBA, Law, IT)
- 📆 Department authorities set application deadlines and special exam dates, fully isolated per department
- ✉️ Automated reminder emails to students via a **node-cron** scheduled job
- 🐛 Solved a real production bug where schedules were leaking globally instead of staying department-scoped
